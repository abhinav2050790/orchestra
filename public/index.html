SPAWN OPENCODE WORKER

Worker = headless opencode run "<prompt>", streamed live onto the bus.

HOW THE BOARD WORKS

  • Chips are live agents — opencode workers, piped commands, or your own terminals.
  • The center MCU is the hub: every event routes through it.
  • Glowing packets on copper traces are realtime events (logs, messages, state writes).
  • LED colors: ● booting ● working ● idle/done ● error/lost
  • Click a chip to open its embedded terminal — wired to the board, streaming live work. Spawned workers auto-open theirs.
  • Keys: S spawn worker · T open terminal · H help · ESC close panels

Any terminal can join: ochre pipe -- yourcommand. Any opencode session gets bus tools via the orchestra MCP server.
